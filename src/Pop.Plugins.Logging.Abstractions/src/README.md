# Pop.Plugins.Logging.Abstractions

This project contains abstractions for plugin logging in the Pop.Plugins framework.

## Purpose
- Defines interfaces and settings for plugin logging.
- Enables plugins to use consistent logging configuration and integration.

## Usage
- Reference this project in plugins to use logging interfaces and settings.
- Implement or use `IPluginLoggingConfigurator` and `PluginLoggingSettings` for logging configuration.

## Features
- Logging configuration abstractions
- Interfaces for plugin logging configurators
- Settings for minimum log level and log enablement

## Integration
- Used by `Pop.Plugins.Logging` and plugin projects for logging support.
